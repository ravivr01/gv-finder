Guidance Value Finder: files to upload to GitHub Pages
1. Upload ALL files in this folder to the root of a PUBLIC repository (Add file > Upload files).
2. Settings > Pages > Deploy from a branch > main > / (root) > Save.
3. Address: https://<your-username>.github.io/<repository-name>/
4. On the iPad: open the address in Safari > Share > Add to Home Screen.
After the first open, Safari keeps a copy so it should also open without internet.
To update later: upload a new index.html over the old one and change V in sw.js (for example gv-finder-v2).
